# Unreleased changes since v0.2.0

LAITA is a self-managed app for one Owner operating the local Admin, Teacher and Student views. [Install and initialize Local](GETTING-STARTED.md) first. Canvas, OpenAI and the assignment verifiers are optional.

| Workflow                             | Try it with your own non-sensitive practice material                                                                                                                                                                                                                                                                                                                                                             |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Phone and home-screen entry          | Open your reachable, trusted HTTPS origin on a phone. Use the Safari home-screen option when available. The app requires a connection to that origin. [Phone setup](GETTING-STARTED.md#iphone-home-screen-entry) · [Synthetic captures](SCREENSHOTS.md)                                                                                                                                                          |
| Course Chat                          | Ask “What must I submit for IA342’s fifth assignment?” and “What do we cover in IA340 Week 5?” Check the displayed source and section. Ask for one assignment at a time. Unsupported or missing evidence produces a refusal or an unavailable result. [Supported public sources](COURSE-GROUNDING.md)                                                                                                            |
| Local drafts and Canvas organization | Generate a lesson draft in standalone Teacher, review the sources, then edit the Markdown. With the optional signed Canvas Teacher session and separate REST credential, preview and confirm an unpublished Page, Assignment or Module. Approved Assignments support title edits, and approved unpublished Modules accept one approved Page or Assignment at a time. [Teacher walkthrough](TEACHING-WORKFLOW.md) |
| Canvas feedback                      | Preview one plain-text comment for the configured Test Student and current attempt. Post explicitly and read the result. An uncertain or unverified write requires checking Canvas before any retry. [Feedback setup and limits](CANVAS.md#canvas-teacher-feedback)                                                                                                                                              |
| GitHub and MongoDB verification      | Use approved practice submissions for a configured course and assignment. Run each verifier and inspect per-attempt results, including partial or unavailable rows. The tools perform bounded read-only checks and neither grade nor post feedback. [Verification setup and limits](CANVAS-VERIFICATION.md)                                                                                                      |
| History and Canvas Chat              | Enable the matching plugin. For local History, create a few Test Student sample questions, then ask Teacher for Count and a Local Summary. For Canvas Chat, ask for Count or Score by full assignment title in the signed Teacher panel. Each uses its configured sample. [History](HISTORY.md#teacher-history-plugin) · [Canvas](CANVAS.md#canvas-chat-plugin)                                                  |
| Admin                                | From a retained History turn with a support reference, sign in locally as Admin and use the exact reference to look up recording and stage metadata. [Diagnostic scope and limits](HISTORY.md#admin-diagnostic-lookup)                                                                                                                                                                                           |

Canvas launch keys identify the signed course session. The optional API tools use the operator's separate backend REST credential. Preview is read-only. A final write requires explicit confirmation of the current target and content and a separate readback. The recheck and write are separate operations.

The update from public v0.2.0 keeps SQLite schema v5 and all five migration checksums. Keep a protected snapshot and the matching build before updating. [Update and recovery](DEPLOYMENT.md#explicit-update-and-recovery)

The [synthetic validation](VALIDATION.md) covers software behavior and integration boundaries. It does not measure model answer accuracy or establish native Safari, physical-device, real speech or live provider acceptance.
